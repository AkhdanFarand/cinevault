# CineVault

CineVault adalah website movie tracker berbasis HTML, CSS, dan JavaScript yang memungkinkan pengguna untuk menyimpan daftar film, menandai film yang sudah ditonton, dan menambahkan film favorit.

## Features

* Add movie from OMDb API
* Watchlist movie
* Watched movie
* Favorite movie
* Movie detail page
* Search movie
* Filter by genre & status
* Sort by title & year
* Responsive UI

## Tech Stack

* HTML
* CSS
* JavaScript
* OMDb API

## Pages

* Home
* Watchlist
* Watched
* Favorites
* Movie Detail
